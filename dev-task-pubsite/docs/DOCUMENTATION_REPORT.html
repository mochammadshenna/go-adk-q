System Architecture

Eight layers from binary entry point to external APIs, each with a single responsibility.

1
Binary
cmd/dev-task-pubsite/main.go
Signal handling · degraded-mode startup · stdio/http dispatch
2
Server
internal/server/server.go
MCP wiring · Gin HTTP · CORS · health endpoint
3
Tools
internal/tools/{issues,prs,sprints,repos}.go
10 MCP tool handlers · panic recovery · ProviderStatus in every response
4
Resources
internal/resources/dashboard.go
MCP App · ext-apps protocol · ui://task-dashboard
5
Providers
internal/providers/{yt,gh}/client.go
YouTrack REST · go-github v68 · circuit breaker per provider
6
Cache
internal/cache/cache.go
TTL cache · stale-while-revalidate · GetResult{Value,Stale,Age}
7
Domain
internal/domain/task.go
Task · PullRequest · Issue · Sprint · RepoStats · CommitDiff · ProviderStatus
8
External
YouTrack REST API · GitHub API
Reached only through provider layer · circuit breaker protects both

Key invariant: every response from layers 3–5 embeds a ProviderStatus{Source, Degraded, StaleAge} field. AI clients can check degraded:true and communicate uncertainty to the user rather than presenting stale data as fresh.

MCP Tools

10 tools across two providers (4 YouTrack, 6 GitHub). All return providerStatus in their response.

YouTrack Tools

list_my_tasks YouTrack
List YouTrack tasks filtered by project, sprint, or state. Uses YouTrack query language under the hood.
project_id* sprint state limit
search_my_tasks YouTrack
Full-text search using YouTrack query language. Supports field projections like assignee: me, State: Open.
query* project_id limit
get_my_sprint YouTrack
Sprint summary: total issue count, state breakdown map (open/in-progress/done), and full task list. Defaults to active sprint.
project_id* sprint_name
create_task YouTrack
Create a new YouTrack task in the specified project. Returns the created task with its YouTrack ID (e.g. PROJ-42).
project_id* summary* description type priority

GitHub Tools

list_pull_requests GitHub
List pull requests for a repository by state. Returns number, title, state, author, branch names, and draft status.
owner* repo* state
get_pull_request GitHub
Full PR detail with CI status from GetCombinedStatus and review decisions from ListReviews. Includes head SHA and diff URL.
owner* repo* number*
list_issues GitHub
GitHub issues only (PRs are excluded via PullRequestLinks != nil check). Supports label and state filtering.
owner* repo* state labels
create_issue GitHub
Create a GitHub issue with title, body, labels, and assignees. Returns the created issue URL and number.
owner* repo* title* body labels
repo_stats GitHub
Repository statistics: stars, forks, open issues (GitHub issues minus PRs), open PRs, default branch, primary language.
owner* repo*
commit_diff GitHub
Full commit diff: message, author, timestamp, changed files with additions/deletions/patch content. Use to link code changes to YouTrack tasks.
owner* repo* sha*
Explanation

Resilience Model

Providers degrade independently. No silent substitution. Stale data is returned with explicit metadata.

⬣ YouTrack Provider

Healthy degraded: false
Stale Cache degraded: true + staleAge
Circuit Open 120s cooldown

⬣ GitHub Provider

Healthy degraded: false
Stale Cache degraded: true + staleAge
Circuit Open 120s cooldown

Resilience-only: YouTrack and GitHub serve complementary data (tasks vs code). The server never substitutes one for the other. If YouTrack is down, yt_* tools degrade; gh_* tools continue unaffected.

Circuit Breaker Thresholds

ParameterValueNotes
Failure threshold5 consecutive errorsPer provider, resets on success
Cooldown duration120 secondsHalf-open probe after cooldown
Cache TTL5 minutesStale data served when circuit is open
Request timeout15 secondsPer HTTP request to provider
Tutorial

Getting Started

Run the server locally and make your first tool call in under 5 minutes.

Prerequisites

🔵

Go 1.25+

Install from go.dev/dl. The module requires go 1.25 in go.mod.

🔑

YouTrack Token

Settings → Account Security → Tokens. Permanent tokens recommended.

🐙

GitHub Token

Settings → Developer Settings → Personal Access Tokens (Classic). Needs repo scope.

Quick start

git clone <repo> && cd dev-task-pubsite

export YOUTRACK_URL=https://youtrack.example.com
export YOUTRACK_TOKEN=perm:your-token
export GITHUB_TOKEN=ghp_your-token
export GITHUB_OWNER=your-org

# HTTP mode (MCP Inspector / curl)
make dev-http

# stdio mode (Claude Desktop)
make dev-stdio

Verify with curl

# Health check
curl http://localhost:9012/health
# {"status":"ok","version":"dev","youtrack":true,"github":true}

# MCP initialize
curl -X POST http://localhost:9012/mcp \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"0.1"}}}'

How-to

Connect Claude Desktop

Add to ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "dev-task-pubsite": {
      "command": "/path/to/dev-task-pubsite",
      "args": ["stdio"],
      "env": {
        "YOUTRACK_URL": "https://youtrack.example.com",
        "YOUTRACK_TOKEN": "perm:your-token",
        "GITHUB_TOKEN": "ghp_your-token",
        "GITHUB_OWNER": "your-org"
      }
    }
  }
}

Build first: run make build to produce the binary at .build/dev-task-pubsite before adding to Claude Desktop.

How-to

Add a New Tool

Four-step pattern followed by all existing tools:

StepFileAction
1internal/providers/yt/ or gh/Add method to provider client with circuit breaker + cache
2internal/domain/task.goAdd result struct if needed
3internal/tools/Create handler file with Register*(s, client)
4internal/server/server.goCall tools.RegisterXxx(s, client) in New()

Handler signature: func(ctx, req *mcp.CallToolRequest, input T) (*mcp.CallToolResult, OutputT, error). The SDK auto-serializes OutputT. Always embed ProviderStatus in OutputT.

Architecture Decision Records

ADR Index

Three accepted ADRs documenting the key architectural choices.

ADR-001

Resilience-only provider fallback

YouTrack and GitHub degrade independently via stale cache + circuit breaker. No silent substitution between providers: they are complementary, not interchangeable.

Accepted
ADR-002

Go MCP SDK v1.6.1

Uses github.com/modelcontextprotocol/go-sdk directly rather than running YouTrack's own MCP proxy. Gives full control over tool schemas, retry logic, and transport.

Accepted
ADR-003

Per-provider circuit breaker design

5-failure threshold, 120s cooldown. State is in-process only (no Redis). Each provider has its own breaker; one provider's failure cannot trip the other's.

Accepted
