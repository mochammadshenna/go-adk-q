Rate Resolution

Three-level pricing fallback

Priority 1 — live
SimpleBooking XML
OTA_HotelAvailRQ · TotalAfterTax · 5-worker pool · circuit breaker (5 fail → 120 s cooldown) · 5-min cache TTL
›
Priority 2 — stored
tb_hrooms.room_rate
Per-brand DB · loaded by hotels team · may be weeks stale · still valid for display
›
Priority 3 — last resort
hotel_starting_price
Central DB scalar · marketing price · no room-type breakdown · never blocks a tool response

Architecture Decision Records

Why it was built this way

ADR Title Status Key files Decision summary
0001 Go + modelcontextprotocol/go-sdk Accepted cmd/…/main.go
internal/server/server.go		 Go over Node.js/Python: single-binary deploy, monorepo consistency, compile-time type safety on tool schemas via generics
0002 Multi-DB Pool with lazy per-brand connections Accepted internal/repository/repository.go Brand DBs connect on first request, not startup; nil stored on failure to avoid reconnect storms; INFORMATION_SCHEMA introspects diverged schemas
0003 Three-level rate fallback chain Accepted internal/rate/rate.go
internal/rate/cache.go		 SimpleBooking XML → stored room_rate → hotel_starting_price; rate errors never bubble as tool errors; 5-min TTL cache, circuit breaker on SB
0004 Gin v1.11 as HTTP transport wrapper Accepted internal/server/server.go Gin handles CORS, recovery, logging middleware; MCP handler wrapped via gin.WrapH; permissive CORS for MCP client compatibility
0005 Vite single-file UI as MCP App resource Accepted ui/src/mcp-app.ts
internal/resources/dashboard.go		 No React/Vue — vanilla TypeScript inlined by vite-plugin-singlefile; embedded via //go:embed; served as MCP resource with ext-apps protocol
0006 resizeImageURL — CSP-safe thumbnail rewriting Accepted internal/repository/hotel.go Pure URL rewriting to CDN; no base64 proxy, no server-side fetch; resourceDomains CSP header pre-authorises images.archipelagohotels.com
0007 Raw hotel_currency code (no symbol map) Accepted internal/repository/hotel.go
ui/src/mcp-app.ts		 ISO 4217 code passed through unchanged; UI uses Intl.NumberFormat; adding new currencies requires zero code change on either side

Configuration Reference

Environment variables

Variable Default Purpose
MYSQL_HOST 127.0.0.1 MySQL host — central DB and all brand DBs must be reachable here
MYSQL_PORT 3306 MySQL port
MYSQL_USER root MySQL user — must have SELECT on all central and brand databases
MYSQL_PASS (empty) MySQL password
MYSQL_DB db_archipelagowebsite Central catalog database — the only hard dependency; server fails to start if unreachable
DEBUG 0 Set 1 to enable debug-level logging of SQL queries, rate calls, and pool operations
url_image_resizer https://images.archipelagohotels.com/ CDN proxy base URL rewritten by resizeImageURL(); must match resourceDomains in tool meta
Build Reference

Make targets

make build
Full build: Vite UI → mcp-app.html, then Go binary → bin/archipelago-hotels-mcp
make build-go
Go binary only — fast iteration when you have not touched the UI
make build-ui
Vite build only — required after any edit to ui/src/mcp-app.ts
make dev-http
Start HTTP mode on :9011 with verbose logging — no Claude Desktop needed
make run-stdio
Start stdio transport mode — connect via Claude Desktop mcp config
go vet ./...
Lint the entire module — also available as make lint
