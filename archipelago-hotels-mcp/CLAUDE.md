# archipelago-hotels-mcp — Claude Code Instructions

Go MCP server for Archipelago Hotels & Resorts (Sentec Tech product). Exposes hotel search, recommendation, and booking tools to Claude Desktop and MCP-compatible clients.

## Build

```bash
make build        # full build: Vite UI + Go binary → bin/archipelago-hotels-mcp
make build-go     # Go only (fast, skips UI rebuild)
make build-ui     # Vite UI only (copies dist → internal/resources/mcp-app.html)
make build-fast   # alias for build-go
go vet ./...      # lint (also: make lint)
make dev-http     # HTTP mode, :9011, verbose
make run-stdio    # stdio transport
```

Any edit to `ui/src/mcp-app.ts` requires `make build` (not `make build-go`).

## Data Architecture

- `Pool.central` → `db_archipelagowebsite` (catalog, brands, regions)
- `Pool.brandDBs` → lazy-connect per brand prefix: `aston`, `neo`, `fave`, `alana`, `harper`, `kamuela`, `quest`, `pba`
- Column introspection via `INFORMATION_SCHEMA` on connect (schema varies per brand)
- PBA special case: table is `tb_hroom` (not `tb_hrooms`), different status column

## Rate Fallback Chain (priority order)

1. SimpleBooking XML API (live) — `OTA_HotelAvailRQ`, 5-worker bounded pool, 5-min TTL cache, circuit breaker (5 failures → 120 s cooldown)
2. `tb_hrooms.room_rate` (stored) — per-brand DB fallback
3. `hotel_starting_price` (central DB) — last resort

## Architecture Rules

- `Pool.BrandDB()` can return `nil` — always nil-check before querying a brand DB.
- Call `HasColumn()` before accessing optional columns (schema varies per brand).
- Tool handlers must `recover()` from panics and return a structured error to the MCP client.
- Currency: use the raw `hotel_currency` code from DB; no hardcoded symbol map.
- MySQL partitioning: tables partitioned by `hotel_id` — always include `hotel_id` in WHERE clauses.
- Never edit `internal/resources/mcp-app.html` directly; it is generated by `make build-ui`.

## UI Protocol

- MIME type: `text/html;profile=mcp-app`
- Resource URI: `ui://hotel-dashboard`
- Tools link via `_meta.ui.resourceUri` + `resourceDomains: ["images.archipelagohotels.com"]`
- `fmtPrice(v, currency)`: raw currency code from `hotel_currency` + `toLocaleString("id-ID")` for IDR
- `resizeImageURL()` rewrites CDN paths → `images.archipelagohotels.com` (no HTTP fetch, CSP-safe)
