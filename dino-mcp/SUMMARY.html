2OPTIONS preflight returns 405CORS error in InspectorAdd corsMiddleware() before routes
3DNS rebinding blocks tunnel403 Forbidden via cloudflaredSet DisableLocalhostProtection: true
4Wrong postMessage protocolUI doesn't render in Claude DesktopUse ui/initialize, not iframe-ready
5Wrong Accept header400 Bad RequestSend both application/json + text/event-stream
