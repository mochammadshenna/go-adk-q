Architecture Decision Records

Why it was built this way

ADR Title Status Key files Decision summary
0001 Go Server Implementation Accepted cmd/dino-mcp/main.go
internal/server/server.go		 Go + go-sdk v1.6.1 over Node/Python; single-binary; same language as parent monorepo for consistency
0002 Gin HTTP Router Accepted internal/server/server.go gin v1.12.0 for route matching, middleware, CORS, JSON responses; MCP handler wrapped via gin.WrapH
0003 MCP Apps View Protocol Accepted internal/resources/dashboard.go
ui/src/mcp-app.ts		 ext-apps SDK; text/html;profile=mcp-app MIME type; postMessage lifecycle (initialize→tool-input→tool-result)
0004 CORS Implementation Accepted internal/server/server.go Permissive CORS (wildcard) for MCP Inspector and Cloudflare Tunnel compatibility; OPTIONS preflight handled
0005 Transport Configuration Accepted cmd/dino-mcp/main.go stdio + Streamable HTTP dual transport; SSE not implemented (removed from MCP spec)
0006 Standalone Dashboard Fallback Accepted internal/resources/dashboard_ui.html Same HTML file serves as MCP App resource AND standalone browser page via GET /dashboard — zero duplication

Build Reference

Make targets

make build
Full build: Vite UI → dashboard_ui.html, then Go binary → bin/dino-mcp
make build-go
Go binary only — fast iteration when you have not touched the UI
make build-ui
Vite build only — required after any edit to ui/src/mcp-app.ts
make dev-http
Start HTTP mode on :9010 with verbose logging — no Claude Desktop needed
make run-stdio
Start stdio transport mode — connect via Claude Desktop mcp config
go vet ./...
Lint the entire module
